# User guide

The tutorials start from a frame and end at a number the crate's tests
lock, or at a call the rustdoc examples compile. The how-to pages answer
one setup question each.

The engine tutorials for the same science, with the `seams` command and
the full trajectories, are in the
[d-SEAMS book](https://docs.dseams.info).

## Tutorials

- [Ice Ih](ice-ih.md) reads the 128-molecule cell and prints the census every language front prints.
- [Bulk ice](bulk-ice.md) compares the cubic diamond with the sI clathrate cell.
- [Cages](cages.md) scores hexagonal and double-diamond membership.
- [Rings](rings.md) counts primitive rings.
- [An ice-water interface](interface.md) reads CHILL+ labels along a slab.
- [Brine](brine.md) measures a planar ice front from an ice assignment.
- [Nucleation](nucleation.md) summarises Lechner-Dellago q6-bar.
