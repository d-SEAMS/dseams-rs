# API reference

The reference for both crates is generated by rustdoc and carried on this
site:

- [`seams`](api/seams/index.html) is the `dseams` crate. Every public type,
  function, field and enum variant has a description, and almost every
  function and type has a runnable example.
- [`seams_sys`](api/seams_sys/index.html) is the `dseams-sys` crate, the raw
  declarations of the C API. `seams::ffi` re-exports it. Most programs use
  the safe crate and never name it. The raw names (`seams_chill_plus`,
  `SEAMS_OK` and the opaque handles) are the C API itself, documented in
  the engine book as [the stable C API](https://docs.dseams.info/stable/c.html).

The same pages are published on docs.rs for each release. To read the
reference for the version in your own project, run `cargo doc --open`
there.

This page is a map of the safe crate by task, to help you find the right
type. Names link to their reference page.

## One frame

[`System`](api/seams/struct.System.html) holds one frame and every analysis
runs on it.

| Item | Role |
| --- | --- |
| `System::new` | An empty frame. |
| `set_ortho`, `set_frame`, `set_atoms`, `read` | Fill the frame. See [Read a trajectory](user-guide/read.md). |
| `count` | The number of atoms. |
| [`diamond8`](api/seams/fn.diamond8.html) | Eight-atom cubic diamond and its lattice constant, for examples. |
| [`nframes`](api/seams/fn.nframes.html) | The number of frames in a trajectory file. |
| [`version`](api/seams/fn.version.html), [`abi`](api/seams/fn.abi.html) | The library's version text and its ABI number, which is 1. |
| [`set_num_threads`](api/seams/fn.set_num_threads.html), [`num_threads`](api/seams/fn.num_threads.html) | The process-global OpenMP width. |

## Ice labels

| Item | Role |
| --- | --- |
| `System::chill`, `System::chill_plus` | The original CHILL and CHILL+. Both return a [`Classification`](api/seams/struct.Classification.html). |
| [`ChillOptions`](api/seams/struct.ChillOptions.html) | Cutoff, species filter, neighbour graph and threshold table. |
| [`Label`](api/seams/enum.Label.html), [`label_name`](api/seams/fn.label_name.html) | The nine label codes and their short names. `counts[label as usize]` is the population. |
| [`ChillRule`](api/seams/enum.ChillRule.html) | The `Published` or `Ovito` threshold table. |
| `System::symmetry` | Per-atom ice shell label: Ih, Ic, stacking disorder or none. |

## Order parameters

| Item | Role |
| --- | --- |
| `System::q4q6` | Local q4 and q6 on the cutoff shell, as [`Q4Q6`](api/seams/struct.Q4Q6.html). |
| `System::steinhardt` | Local q_l, and the Lechner-Dellago neighbour mean when `average` is set. |
| `System::ql` | The same on a named neighbour graph. See [`OrderOptions`](api/seams/struct.OrderOptions.html). |
| `System::q6bar` | q6-bar, its mean and median, and the number of atoms above `ice_cut`. See [`Q6Bar`](api/seams/struct.Q6Bar.html). |

## Neighbours, rings and cages

| Item | Role |
| --- | --- |
| `System::neighbours`, `System::knn`, `System::neighbour_degree` | A cutoff or mutual list, a k-nearest list, or the degree of every atom. |
| [`Neighbours`](api/seams/struct.Neighbours.html) | `nnz`, `degrees`, and `pairs`, which yields `NeighbourPair`. |
| [`Graph`](api/seams/enum.Graph.html) | How neighbours are chosen: `Cutoff`, `Mutual` or `Seeded`. |
| `System::rings`, `System::six_ring_fraction` | Primitive rings. [`Rings`](api/seams/struct.Rings.html) has `size`, `vertices`, `histogram`, `fraction` and `iter`. |
| `System::cages`, `System::signature_cages` | Hexagonal and double-diamond membership, or closed cages of one signature. |
| [`Cages`](api/seams/struct.Cages.html), [`CageCounts`](api/seams/struct.CageCounts.html), [`CageLabel`](api/seams/enum.CageLabel.html) | Cage membership as owned results: the four disjoint counts and the per-atom code. |
| [`SignatureOptions`](api/seams/struct.SignatureOptions.html), [`SignatureMatch`](api/seams/struct.SignatureMatch.html) | A signature such as `512`, and the number of cages and atoms it matches. |

## Distributions, bonds and topology

| Item | Role |
| --- | --- |
| `System::rdf`, `System::running_cn`, `System::coordination` | The partial radial distribution function, the running coordination number, and its integral to `rmax`. |
| `System::density` | Number density along one [`Axis`](api/seams/enum.Axis.html). |
| `System::hbonds` | The hydrogen-bond count. See [`BondOptions`](api/seams/struct.BondOptions.html). |
| `System::site_table`, `System::contact_pairs`, `System::domains` | Site kinds, unlike contacts, and the largest polar or apolar domain. |
| `System::fingerprint` | The topological fingerprint of each molecule. [`Fingerprint`](api/seams/struct.Fingerprint.html) exposes `key`, `atom` and `rings`. |
| `System::prisms`, `System::monolayer` | Prism stacks, and a ring histogram for a monolayer. |

## Brine

| Item | Role |
| --- | --- |
| `System::brine` | A planar ice front from an ice assignment. [`BrineOptions`](api/seams/struct.BrineOptions.html) selects species, bins and axis. |
| [`Brine`](api/seams/struct.Brine.html) | The result handle, with `fronts`, `rejection`, `profile` and `pockets`. |

Lengths are in angstroms and molality is in mol/kg. The
[brine tutorial](user-guide/brine.md) runs all four reports.

## Errors and handles

| Item | Role |
| --- | --- |
| [`Error`](api/seams/enum.Error.html), [`Status`](api/seams/enum.Status.html) | A failed call, with `status`, `code` and `message`. See [Handle errors](user-guide/errors.md). |

The handles `System`, `Neighbours`, `Rings`, `Cages`, `Fingerprint` and
`Brine` are `Send` and not `Sync`. Dropping a handle frees the native
object behind it.
